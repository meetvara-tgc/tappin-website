# Tappin Website — SEO Keyword Map

> **Strategy:** Norway-first targeting. Each page targets **1 focus keyword + 3–4 secondary keywords** chosen for high commercial intent + low-to-medium competition in the Norwegian event-tech market. Expandable to other Nordic markets (Sweden, Denmark, Finland, Iceland) by translating + adding hreflang variants.

> **Where each keyword appears on its page:** title, meta description, URL slug (where possible), H1, first paragraph, at least one H2/H3, logo alt text, body copy, and OG/Twitter tags. JSON-LD also references the keyword via the `description` and `name` fields.

## How each focus keyword is targeted

For every page, the focus keyword appears in:

- **Title tag** — under 60 characters
- **Meta description** — under 160 characters, keyword in the first half
- **Canonical URL** — slug matches the live tappin.no structure
- **H1** — single H1 per page, keyword inside
- **First paragraph** — opening sentence or second sentence
- **At least one H2 or H3** — supporting heading on the same page
- **Logo alt text** — header + footer logo alt includes the keyword
- **OG + Twitter tags** — social previews carry the keyword
- **JSON-LD** — `name`, `description` fields embed the keyword
- **Internal links** — pages cross-link using the keyword as anchor text where natural

Secondary keywords are woven into:

- Body paragraphs (in feature blocks, FAQ sections, use-cases)
- Subheadings (H3) inside the page
- Alt text on supporting visuals
- Internal link anchor text on outbound links to related pages

## Why these keywords (rationale)

**Norway-first commercial intent:** All focus keywords include "Norway" or a Norwegian-market modifier. This filters competition to local players and matches the search behaviour of B2B buyers in Norway researching tools.

**Buyer-stage coverage:**
- *Top of funnel* — `event management blog Norway`, `event engagement Norway` (educational searches)
- *Mid funnel* — `event platform Norway`, `hybrid event platform Norway`, `digital event platform Norway` (comparison shopping)
- *Bottom of funnel* — `event platform demo Norway`, `event platform DPA Norway`, `event registration software Norway` (purchase-intent)

**Long-tail dominance over broad terms:** We avoid competing for global terms like "event platform" (dominated by Hopin, Bizzabo, Cvent). Each Tappin keyword pairs the category with "Norway," which dramatically lowers competition while matching local intent.

**Expansion path:** When you're ready to expand into Sweden, Denmark, Finland or Iceland, swap "Norway" for the country term (`event platform Sverige`, `event platform Danmark`, etc.) on duplicate language pages with `hreflang` annotations.

## Internal linking strategy (already implemented)

Every page is connected with at least these cross-links:

- **Header nav (every page)** — dropdowns expose all 4 platform pages and all 3 solution pages
- **Footer (every page)** — 4 columns linking to every other page
- **Body cross-links by topic cluster:**
  - Solution pages (physical / hybrid / digital) → link to all 4 platform pages by feature
  - Platform pages → link to the next platform page + relevant solution pages
  - Blog post → 8 contextual links to physical, hybrid, digital event pages + 4 platform pages
  - Stories index → all blog posts
  - About → contact page + team
  - Contact → about + privacy
  - Legal pages → cross-reference each other (Privacy ↔ GDPR ↔ DPA)
- **Anchor text** uses focus keyword or close variant on internal links to the destination page

## Quick-wins after launch

1. **Submit `sitemap.xml`** to Google Search Console + Bing Webmaster Tools.
2. **Verify `robots.txt`** allows crawling from Google, Bing, GPTBot, ClaudeBot, PerplexityBot, Google-Extended.
3. **Add a real 1200×630 OG image** at `assets/og-image.png` (placeholder reference already wired up across all pages).
4. **Build backlinks** from Norwegian event-industry directories, partner sites (Tekna, NOKU, EHiN), and customer case studies on third-party sites.
5. **Track ranking** for each focus keyword in Search Console + a tool like Ahrefs / SEMrush.
6. **Expand the blog** — every 2–3 weeks, publish a new Stories post targeting a long-tail Norwegian event keyword to build topical authority.
